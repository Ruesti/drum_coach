# Today-Illustrationen

Generiert am 23.09.2026 mit Qwen-Image (Apache 2.0) auf der eigenen GPU-Box.
Stil nach acht Runden mit dem Auftraggeber: echte Fotos in echten Räumen,

aus Action und ruhigen Momenten, Menschen gemischt. Format 16:9, 1080×608
(Entscheidung 23.09.: das alte 2,4:1-Band schnitt Haare und Sticks ab).
